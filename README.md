# WhatSend Pro

**WhatsApp professionnel, simplement.**

SaaS pour connecter un numéro WhatsApp Business via les mécanismes officiels de Meta, centraliser les conversations et créer des automatisations.

## MVP
- Authentification
- Connexion WhatsApp Business
- Dashboard
- Messages et conversations
- Contacts
- Modèles
- Automatisations
- API / webhooks
- Statistiques
- Usage et facturation

## Stack
React + Vite · Supabase · WhatsApp Business Platform / Meta
